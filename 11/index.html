    第 11 天 - 查找文件

    • 教学视频：Lesson video（英文）
    • 补充视频：Finding things（英文）

    引言

    今天我们来看如何快速、高效地查找文件，以及查找文件里的文本内容。

    明明知道某个文件或某项设置就存在于系统里，却怎么也找不到，实在让人抓狂！掌握今天的命令，你管理服务器时会自信得多。

    今天你会认识几个实用工具：

    • locate
    • find
    • grep
    • which

    今日任务

    • 找出所有内容里含有 “Permission” 一词的文件

    操作步骤

    locate

    如果你要找一个名为 access.log 的文件，最快的办法是用 “locate”：

    $ locate access.log
/var/log/apache2/access.log
/var/log/apache2/access.log.1
/var/log/apache2/access.log.2.gz

    （如果 locate 还没装，用 sudo apt install plocate 装上即可）

    可以看到，默认情况下你搜 “something”，它会按 “*something*” 来匹配。它速度飞快，因为查的是索引；但一旦索引过期或缺失，结果就可能对不上。索引由 updatedb 命令生成——通常由 cron 每晚自动跑一次。所以对最近新增的文件，索引可能是旧的，值得手动执行一次 sudo updatedb 来刷新。

    find

    find 命令沿着目录结构逐层往下搜，按条件匹配文件——条件可以是文件名，也可以是大小、最后修改时间等等。试试这两个例子：

    find /var -name access.log
find /home -mtime -3

    第一条查找名字为 “access.log” 的文件；第二条查找 /home 下最近 3 天内修改过的所有文件。

    这两条会比 locate 慢，因为它们直接遍历文件系统，而不是查索引。另外，find 以你当前登录用户的权限运行，所以全盘搜索时你会看到大量 “Permission denied” 报错。在命令前面加上 sudo，当然就能以 root（根用户）身份运行——或者用 grep 把报错过滤掉：find /var -name access.log 2>&1 | grep -vi "Permission denied"。

    上面这些只是冰山一角。去读读“资源”一节里的文章，尽可能多动手练——花在 find 上的时间绝不会白费。

    grep -R

    “grep” 不只能在一个指定文件里搜文本——你可以把整个目录结构交给它，让它递归地一路搜下去，还会跟随所有符号链接（symlink）（小写的 -r 则不会这么做）。当你“只知道”某个东西“肯定在某处”，却想不起具体在哪时，这招特别趁手。

    举个例子：你知道 “PermitRootLogin” 是 ssh 的一个参数，写在 /etc 下某个配置文件里，但想不起来具体是哪个文件，那就来一句：

    grep -R -i "PermitRootLogin" /etc/*

    由于它只对纯文本文件有效，所以最适合用在 /etc 和 /var/log 这两个目录里。（注意那个 -i：它让搜索“不区分大小写”，即使文件里写的是 “Permitrootlogin” 也能找出来。）

    你可能已经见过 /var/log/access.log.2.gz 这样的日志——它们是为了省磁盘空间而压缩过的旧日志，用 less 读不了，用 grep 也搜不着。好在还有 zless 和 zgrep，它们不但能对付压缩文件，普通文件也一样在行。

    which

    有时候你会想知道一条命令到底是从哪儿来的。输入 nano 后它启动了，那这个 nano 二进制文件是哪来的？一般的规则是：系统会按你的 “path” 里设置的各个位置逐个查找。想看看 path 里都有什么，输入：

    echo $PATH

    想知道 nano 从哪来，输入：

    which nano

    再对 grep、vi、service 和 reboot 都试试。你会发现它们几乎总待在名为 bin 的子目录里，而且这样的 bin 还不止一个。

    扩展

    find 命令的 -exec 功能极其强大。

    但“查找”这门功夫远不止于此！你不光能追查文件的内容，还能用 lsof、fuser 这类命令查清文件的**使用情况**——比如现在有哪些进程正开着它。

    从“资源”部分的链接里挑几个例子动手试试。

    本课命令速查（中文版新增）

    命令 用途
    locate 按名称快速查文件（查索引；sudo updatedb 可刷新索引）
    find /var -name access.log / find /home -mtime -3 按名称 / 按最后修改时间直接遍历查找
    grep -R -i "PermitRootLogin" /etc/* 在目录树中递归搜索文本（-i 不区分大小写）
    zless / zgrep 读取 / 搜索压缩日志（对普通文件同样有效）
    echo $PATH 查看命令的搜索路径
    which nano 查看命令对应的可执行文件位置
    lsof / fuser 查看文件被哪些进程使用（扩展）
