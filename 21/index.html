    第 21 天 - 下一步？

    • 教学视频：Lesson video（英文）

    这是什么情况——这门课不是只有 20 天吗？

    没错，但希望你能继续学下去，所以这里给出几个可以考虑的方向。

    继续玩你的服务器

    课程用的那台服务器你已经很熟悉了，继续拿它练手吧。也许卸掉 Apache2，装上竞品 NGINX？或者持续统计 ssh“攻击者”的动向？都可以。免费的 AWS 能用一年，每月 5 美元的服务器，你也总能给自己找到一个说得过去的理由。

    加几个你会用到的服务

    现在你应该有能力照着教程，安装并运行自己的 Minecraft、Wordpress、WireGuard VPN 或 Mediawiki 实例了。过程中难免遇到些问题——那都是宝贵的经验！

    可以看看 Server World，找找灵感。

    延伸学习

    别再刷 Gnome、KDE 或 i3 的文章了——去看看“20 Linux commands every sysadmin should know”这类文章吧。动手试试这些命令，深挖它们的选项。就像学外语要背单词，这些“词”你得先认识，才谈得上使用！

    如果还没逛过 Linux Journey，不妨去看看——尤其当你对 Linux 还很陌生、想见识一种不同的学习路径时。Linux 101 Hacks 也是个好资源。

    到 SadServers.com 做些挑战题，练一练你学到的东西。那里收集了一系列场景，你要在其中对一台 Linux 服务器完成操作、修复问题，甚至“黑”进去。不用拿自己的服务器冒险就能锻炼排障技能，非常划算。

    想让命令行速度突飞猛进，试试 Command Line Challenge、practicelinux.com、learnshell.org 和 commandlinefu.com。

    如果你的进阶目标是转入 DevOps，可以看看 DevOps Roadmap。

    认证

    如果你想以 Linux 为职业，而手上还没有一份亮眼的简历，那就该把拿到一张 Linux 认证作为目标。真正算数的证书/路线其实只有三条：

    • CompTIA Linux+ —— 一次考试搞定，不绑定发行版，但市场上含金量不算高。如果你不想深入 Linux，或者你本来就在修其他 CompTIA 路线、而且雇主愿意报销，那就选它。
    • LPI LPIC-1: Linux Administrator —— 对其各类认证/课程的覆盖范围有非常详尽的说明。这些考试可以钻得很深，凡是纯 Linux 能想到的内容几乎都有覆盖。雇主认可度不算高，但知识本身绝对保值。
    • Red Hat —— 你可能在这里花掉大量时间和金钱，但很可能物有所值！它面向 RedHat Enterprise Linux 发行版及其独有之处，是实操考试（其他两家都是选择题），在企业圈里名声很响，简历上非常亮眼。

    即便你不想要/不需要证书，这些参考资料里的大纲也能帮你在自学中找准该发力的方向。

    表达你的感谢！

    支持与贡献

    Linux Upskill Challenge 免费且开源——并将永远如此。

    维护和改进这个项目需要持续投入时间、用心和精力：更新内容、管理社区、维护基础设施，以及支持世界各地的学习者。

    目前由 Livia Lima 一人维护这些材料。但她只有一个人，而且正处于人生的转折期；社区的支持能让她有时间把这个项目维持在健康、开放、不断演进的状态。

    如果 Linux Upskill Challenge 帮你学到了东西、获得了成长、对 Linux 更有信心，而且你有能力提供资金支持，你的帮助将带来切实的不同。捐赠或赞助。

    支持出于自愿，但学习的机会不应附带条件。

    如果你想以金钱之外的方式贡献，可以这样做：

    • 在我们的频道里回答其他学员的问题。陪一位朋友走完这段挑战。
    • 修正错别字、死链等——向源材料提交勘误请求。
    • 提出改进建议——向源材料提交功能请求。
    • 协助管理 Lemmy、Reddit 或 Discord。你是其中一个（或几个）平台的高手吗？来帮忙管理吧。

    感谢你成为这个社区的一员，祝你 Linux 之旅愉快！
