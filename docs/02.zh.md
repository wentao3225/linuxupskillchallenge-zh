## 引言

在 Linux 和 Unix 世界之外，大多数计算机用户如今已不怎么在命令行上花时间，但作为 Linux 系统管理员，命令行就是你的默认工作环境——所以你必须把它练熟。

使用 Windows、Apple 的 macOS（乃至新版 Linux 桌面）这类图形桌面时，呈现在你面前的越来越多是简单的“存放位置”——“图片”、“音乐”之类；但只要你稍微懂点技术就会意识到，这一切底下其实是一个由“文件夹”组成的层级式“目录结构”（比如 Windows 上的 *C:\Users\Steve\Desktop*、macOS 上的 */Users/Steve/Desktop*，而桌面 Linux 系统上则是 */home/steve/Desktop*）。

从现在起，课程会为每个主题给你指一批不错的在线资源，然后布置一组简单的任务让你完成。你完全可以自行 google 其他在线资料、翻手头的书等等——事实上，**逼你做一点自己的调查研究**正是这门课程设计上的一个基本要素。再资深的系统管理员也会上网搜索命令的用法建议——所以你也越早养成这个习惯越好！

## RTFM

现在正好提一下 Linux 的众多优点之一：它的设计初衷就是让你了解这台系统、学会使用它。以文字手册、指南和论坛形式存在的文档资料，将占据你这段旅程中的大部分时间。

专有系统虽然也有一些免费文档，但更常见的情形是靠付费客户支持来解决问题、或弄清某个任务该怎么执行。Linux 当然也能这么做（Canonical、RedHat、SuSE 都提供同类付费支持），但你多半不会走这条路。何况你是来学习的，所以……

于是我们就绕不开那个著名的缩写 [RTFM](https://en.wikipedia.org/wiki/RTFM)（Read The Fucking Manual，“去读手册”）。学习一条命令时，**第一件事**就是读手册。我们会过一遍获取这些信息的各种途径，但如果搜到最后还是不够明白，你随时可以在论坛和其他社区里[提出一个写得漂亮的问题](https://opensource.com/life/16/10/how-ask-technical-questions)。

先从 `man` 命令说起。每个装好的应用在手册里都有自己的页面，比如翻到 `pwd` 那一页，就能看到它的完整语法细节：

```bash
man pwd
```

你还可以试试：

```bash
man cp
man mv
man grep
man ls
man man
```

> **关于 Ubuntu Minimized 的说明——如果你用的是[本地服务器/虚拟机](00-Local-Server.md)：**
> 由于这是精简/裁剪版的 Ubuntu Server，很遗憾默认不会安装 `man-db` 软件包，你也就没有手册页可用。不想解除精简模式的话，装上所需的软件包即可：
> `sudo apt install man-db manpages manpages-dev`

你会看到，手册页对命令的详细语法来说非常出色，但很多写得极其简略，另一些则细节多得让人望而生畏！

这也正是 `tldr` 如此强大的原因！可以用 `snap install tldr` 来安装，或者按[它的 wiki](https://github.com/tldr-pages/tldr/wiki/Clients#official-console-clients) 了解更多安装选择。

```bash
$ tldr pwd
pwd
Print name of current/working directory.More information: https://www.gnu.org/software/coreutils/pwd.

 - Print the current directory:
   pwd

 - Print the current directory, and resolve all symlinks (i.e. show the "physical" path):
   pwd -P
```

如果你记得某个关键词、或大概知道这条命令该干什么，可以试试 `apropos` 或 `man -k`，像这样：

```bash
$ apropos "working directory"
git-stash (1)        - Stash the changes in a dirty working directory away
pwd (1)              - print name of current/working directory
pwdx (1)             - report current working directory of a process

$ man -k "working directory"
git-stash (1)        - Stash the changes in a dirty working directory away
pwd (1)              - print name of current/working directory
pwdx (1)             - report current working directory of a process
```

但你很快就会发现，并非每条命令都有能用 `man` 阅读的手册。这类命令就内建在 shell 本身之中，我们称之为[内建命令（builtin commands）](https://www.gnu.org/software/bash/manual/html_node/Shell-Builtin-Commands.html)。

两者有重叠之处（即有的内建命令也带手册页），但当 `man` 查不到时，我们就用 `help` 来显示它们的信息。

```bash
$ man export
No manual entry for export

$ help export
export: export [-fn] [name[=value] ...] or export -p
    Set export attribute for shell variables.

    Marks each NAME for automatic export to the environment of subsequently
    executed commands.  If VALUE is supplied, assign VALUE before exporting.

    Options:
      -f        refer to shell functions
      -n        remove the export property from each NAME
      -p        display a list of all exported variables and functions

    An argument of `--' disables further option processing.

    Exit Status:
    Returns success unless an invalid option is given or NAME is invalid.
```

判断一条命令是不是内建命令，最好的办法是用 `type` 查一查：

```bash
$ type export
export is a shell builtin
```

最后，`info` 命令读取以 [info](https://en.wikipedia.org/wiki/Info_(Unix)) 格式存储的文档。

## 在文件结构中导航

* 先从手册读起：`man hier`
* `/` 是整棵文件夹分支树的“根”（文件夹也就是“目录”）
* 任何时刻你都“处于”系统的某个部分——`pwd`（“print working directory”）命令会显示你身在何处
* 一般而言，你的提示符也被配置成至少显示一部分这类信息，所以当我“在” _/etc_ 目录里时，提示符可能是 `steve@202.203.203.22:/etc$`，也可能只是 `/etc: $`
* `cd` 用来切换到不同区域——比如 `cd /var/log` 会带你进入 `/var/log` 文件夹。动手试试，然后用 `pwd` 验证一下，再看看提示符是否随位置变化。
* 输入 `cd ..`（读作 “cee dee dot dot”）可以沿目录树向“上”走。试一试：先 `cd` 到 `/var/log/`，然后 `cd ..`，再 `cd ..` 一次——仔细盯着提示符，或者每次敲一下 `pwd`，弄清自己当前的工作目录。
* “相对”位置以你当前的工作目录为基准——比如先 `cd /var`，`pwd` 会确认你“在” `/var` 里；此时去 `/var/log` 有两种走法：用 `cd /var/log` 给出完整路径，或用 `cd log` 只给“相对”路径。
* 单独一个 `cd` 总会把你带回你自己的“家目录”（home directory），也记作 `~`（“波浪号”）（注意：这一点与 DOS/Windows 不同）
* 文件夹里有哪些文件？`ls`（list，列举）命令会列出文件和子文件夹。和许多 Linux 命令一样，它也有选项（俗称“开关”）来改变命令的含义或输出格式。先试一下 `ls`，再试 `ls -l -t`，然后试试 `ls -l -t -r -a`
* 按照惯例，以 `.` 开头的文件被视为隐藏文件，`ls` 和许多其他命令都会无视它们；`-a` 开关会把它们显示出来。你的家目录里应该能看到不少隐藏文件。
* 关于开关再提一句：一般来说，大多数 Linux 命令接受一个或多个“参数”，以及一个或多个“开关”。比如 `ls -l /var/log` 里，“`-l`” 是表示“长格式”的开关，“`/var/log`” 则是“参数”。许多命令接受的开关相当多，而且通常可以合并着写（所以从现在起，请用 `ls -ltra`，而不是 `ls -l -t -r -a`）
* 在家目录里输入 `ls -ltra`，看最左边那一列：行首第一个字符是 `d` 的条目是目录（文件夹）而非文件。它们还可能以不同的颜色或字体显示——如果没有，加上 `--color=auto` 开关即可（比如 `ls -ltra --color=auto`）

## 目录的基本操作

* 用 `mkdir` 命令可以新建文件夹/目录：先回到家目录，输入 `pwd` 确认自己确实在正确的位置，然后创建一个目录——比如想建一个叫 “test” 的，直接输入 `mkdir test` 即可。现在用 `ls` 命令看看结果。
* 你可以继续创建更多目录，在目录里再嵌套目录，然后用 `cd` 命令在它们之间穿行。
* 想把这个目录挪进另一个目录，用 `mv` 并指定要移动的路径。
* 删除（或移除）目录：目录为空时用 `rmdir`；里面还剩文件或其他目录时，就用 `rm -r`。

## 文件的基本操作

* 用 `touch` 命令可以新建空文件，正好拿来再多玩一玩 `ls` 命令。
* 想把这个文件挪到另一个目录，用 `mv` 并指定要移动的路径。
* 删除（或移除）文件，用 `rm`。

## 小结

能在命令行里自信地穿行于目录结构非常重要，所以别以为可以跳过！不过，这些技能在你接下来二十天的课程里会天天用到，就算一时没有“开窍”，也别灰心。

## 扩展

如果这些对你来说早已烂熟，那么：

* 学学 `pushd` 和 `popd`，轻松在多个目录之间往返。执行 `pushd /var/log` 会把你带到 `/var/log`，同时记住你来时的位置。你可以一次 `pushd` 好几个目录。动手试试：`pushd /var/log`、`pushd /dev`、`pushd /etc`、`pushd`、`popd`、`popd`。注意不带参数的 `pushd` 会在最近 _压入_ 的两个目录之间来回切换，而[更复杂的跳转同样可行](https://opensource.com/article/19/8/navigating-bash-shell-pushd-popd)。最后，`cd -` 也能把你带回上一个访问过的目录。

## 本课命令速查（中文版新增）

| 命令 | 用途 |
| --- | --- |
| `man <命令>` | 查看命令的手册页 |
| `tldr <命令>` | 给出命令的简明示例（用 `snap install tldr` 安装） |
| `apropos` / `man -k` | 按关键词搜索手册页 |
| `help <命令>` | 查看 shell 内建命令的帮助 |
| `type <命令>` | 判断命令是否为 shell 内建命令 |
| `info <命令>` | 阅读 info 格式的文档 |
| `pwd` | 显示当前所在目录 |
| `cd` | 切换目录（`cd ..` 上一级、`cd` 回家目录、`cd -` 回上一目录） |
| `ls` | 列出目录内容（`-l -t -r -a` 长格式/按时间/逆序/含隐藏文件） |
| `mkdir <目录名>` | 新建目录 |
| `mv <源> <目标>` | 移动文件或目录 |
| `touch <文件名>` | 新建空文件 |
| `rm <文件>` / `rm -r <目录>` | 删除文件 / 删除整个目录 |
| `rmdir <目录>` | 删除空目录 |
| `pushd` / `popd` | 在多个目录间跳转并记录来路（扩展内容） |
