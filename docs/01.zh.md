## 引言

现在你应该已经有一台装好最新 Ubuntu Server LTS（长期支持版）的远程服务器了，接下来由你独自管理它。要成为全面的 Linux 服务器管理员，你迟早要适应不同的 Linux 版本，但就目前而言，Ubuntu 是个很好的起点。

一旦你在命令行上有了手感，你会发现这些技能不但能迁移到所有主流 Linux 发行版，还能迁移到 Android、Apple 的 macOS、OpenBSD、Solaris 和 IBM AIX 上。整个课程我们都在 Linux 上操作——但其实大部分内容适用于任何源自 [UNIX 操作系统](https://youtu.be/tc4ROCJYbm0)的系统，它们之间最主要的区别只是图形界面（Gnome、KDE 之类）——而这些你通通都用不到！

## 使用 SSH 客户端

远程登录早年用的是简陋的 telnet 协议，现在大家都改用安全得多的 SSH（Secure SHell）协议。**如果你的服务器是本地虚拟机或 WSL，直接用服务器自己的控制台/终端就行，这一节可以跳过。** 我们会在[第 3 天](03.md)深入服务器端的 SSH，但会用 [SSH 客户端](https://www.ssh.com/academy/ssh/client)是系统管理员的基本功，不妨现在就练起来。

### macOS 和 Linux

macOS 上一般通过 **Terminal.app** 进入命令行，它就在“应用程序”的“实用工具”子文件夹里。

带菜单的 Linux 发行版中，终端通常在“应用程序菜单 -> 附件 -> 终端”、“应用程序菜单 -> 系统 -> 终端”或“菜单 -> 系统 -> 终端程序（Konsole）”里——或者直接搜索“终端”更快。很多情况下按 `Ctrl+Alt+T` 也能弹出终端窗口。

打开“终端”会话后，就可以这样使用命令行 **ssh** 客户端：

`ssh user@<ip address>`

例如：

`ssh support@192.123.321.99`

如果服务器配置的是 SSH 公钥登录（AWS、Azure、GCP 默认都是这样），就需要用 `-i` 参数指明私钥的位置来证明身份，通常像这样：

`ssh -i ~/.ssh/id_rsa support@192.123.321.99`

用 `.ssh/config` 功能可以让整个连接过程行云流水——见下方“扩展”部分的“SSH client configuration”链接。

### Windows

较新的 Windows 10/11 已经内置了同一个命令行客户端，但需要在“设置”、“应用”、“应用和功能”、“管理可选功能”、“添加功能”里[启用](https://learn.microsoft.com/en-us/windows/terminal/tutorials/ssh) OpenSSH 客户端。

Windows 上还有不少 SSH 客户端可选（[PuTTY](https://www.chiark.greenend.org.uk/~sgtatham/putty/latest.html)、[MobaXterm](https://mobaxterm.mobatek.net/)、[Termius](https://termius.com/free-ssh-client-for-windows) 等）；如果你的 Windows 版本比 10 还老，建议安装 PuTTY。

另外，你也可以安装 [Windows Subsystem for Linux](https://learn.microsoft.com/en-us/windows/wsl/install)（WSL），它会给你一个完整的本地 Linux 命令行环境，其中就包含 SSH 客户端 _ssh_。

无论用哪个客户端，第一次连接服务器时你可能会收到“正在连接新服务器”的警告，并询问是否[缓存主机密钥](https://www.ssh.com/blog/what-are-ssh-host-keys)。答案是：要。输入/点击 **Yes** 即可。

现在先不用操心 SSH 会话的安全或服务器加固，我们会在[第 3 天](03.md)专门处理。

当前只需登录你的服务器，并记住：Linux 对用户名和密码都区分大小写。

你会花大量时间在 SSH 客户端里，所以值得花点时间把它调教顺手。至少试试“白底黑字”和“黑底绿字”两种配色，再换几款等宽字体试验一下（“Ubuntu Mono” 免费下载，观感很好）。

在远程会话和本地桌面之间复制粘贴文本也非常常用，花点时间把这套操作练熟。

你还可以试着从家里、公司——甚至手机上——登录服务器，手机端可以用 [Termux](https://termux.dev/en/)、[Termius for Android](https://termius.com/free-ssh-client-for-android) 或 [Termius for iPhone](https://termius.com/free-ssh-client-for-iphone) 这类应用。作为服务器管理员，你得习惯从任何地方登录。也可以试试 [consolefish](https://www.serfish.com/console/)、[ShellHub](https://www.shellhub.io/) 这类基于 JavaScript 的 SSH 客户端，但它们要求你比大多数系统管理员能接受的程度更信任第三方——碰生产系统时要慎重。

要退出登录，输入 `exit` 或直接关掉终端即可。

## 登录你的服务器

## 服务器基本信息 { #general-information-about-the-server }

用 `lsb_release -a` 查看你使用的发行版和版本号。[lsb_release](https://refspecs.linuxfoundation.org/LSB_3.0.0/LSB-PDA/LSB-PDA/lsbrelease.html) 在你的服务器上可能并不存在，因为它没有被广泛采用；但同样的信息永远可以从系统文件 [os-release](https://www.man7.org/linux/man-pages/man5/os-release.5.html) 里拿到，输入 `cat /etc/os-release` 即可查看。

`uname -a` 会打印[系统信息](https://www.man7.org/linux/man-pages/man1/uname.1.html)，能看到内核版本、硬件平台等不少有意思的东西。

`uptime` 显示[系统已经运行了多久](https://www.man7.org/linux/man-pages/man1/uptime.1.html)。比起 `cat /proc/uptime` 吐出的那堆[奇怪数字](https://unix.stackexchange.com/questions/753868/proc-uptime-command-gives-weird-result)，它可读多了。

`whoami` 打印你登录用的[用户名](https://www.man7.org/linux/man-pages/man1/whoami.1.html)；`who` 显示[当前有哪些人登录](https://www.man7.org/linux/man-pages/man1/who.1.html)；`w` 还会显示[他们在做什么](https://www.man7.org/linux/man-pages/man1/w.1.html)。

## 硬件信息

`lshw` 能给出[详细的硬件配置信息](https://manpages.ubuntu.com/manpages/trusty/en/man1/lshw.1.html)，还带一堆参数可以筛出你想看的内容，但它不是唯一的硬件查看工具，常用的命令还有：

* `lscpu` 查看 [CPU 架构信息](https://www.man7.org/linux/man-pages/man1/lscpu.1.html)
* `lsblk` 列出[块设备](https://www.man7.org/linux/man-pages/man8/lsblk.8.html)
* `lspci` 列出所有 [PCI 设备](https://www.man7.org/linux/man-pages/man8/lspci.8.html)
* `lsusb` 列出 [USB 设备](https://www.man7.org/linux/man-pages/man8/lsusb.8.html)

## 内存与 CPU 占用

别慌！Linux [不会吃掉你的内存](https://linuxatemyram.com/)。想查看系统的[内存使用](https://www.man7.org/linux/man-pages/man1/free.1.html)情况，用 `free -h`；`vmstat` 还能给出一些[内存统计](https://www.man7.org/linux/man-pages/man8/vmstat.8.html)。

`top` 相当于 Linux 的[任务管理器](https://www.man7.org/linux/man-pages/man1/top.1.html)，会显示进程和资源占用情况；`htop` 是它的[交互式](https://www.man7.org/linux/man-pages/man1/htop.1.html)美化版。

## 磁盘占用

用 `df -h` 查看[磁盘空间](https://www.man7.org/linux/man-pages/man1/df.1.html)使用情况；想估算目录的[大小](https://www.man7.org/linux/man-pages/man1/du.1.html)，则用 `du -h`。

## 网络流量

> **译注**：本节与英文原版顺序相反——先介绍现代命令 `ip address`，再提旧命令 `ifconfig`。现代 Ubuntu 默认已不自带 `ifconfig`。

用 `ip address` 可以对网络接口及其 IP 地址有个整体了解（它是旧命令 `ifconfig` 的现代替代品），但它不显示带宽占用。

看流量可以用 `netstat -i` 的[静态视图](https://www.man7.org/linux/man-pages/man8/netstat.8.html)，或用 `ifstat` 的[连续视图](https://www.man7.org/linux/man-pages/man8/ifstat.8.html)。要中断 `ifstat`，按 `CTRL+C`。

想看更细的流量信息，`sudo iftop -i enp1s0` 有个[不错的展示界面](https://manpages.ubuntu.com/manpages/xenial/man8/iftop.8.html)。*把 `enp1s0` 换成你想抓流量的网卡接口名。* 按 `q` 退出监控视图。

## 本课命令速查（中文版新增）

| 命令 | 用途 |
| --- | --- |
| `lsb_release -a` / `cat /etc/os-release` | 查看发行版和版本 |
| `uname -a` | 内核版本、硬件平台等系统信息 |
| `uptime` | 系统已运行时长 |
| `whoami` / `who` / `w` | 当前用户 / 登录者 / 登录者在干什么 |
| `lshw` / `lscpu` / `lsblk` / `lspci` / `lsusb` | 硬件 / CPU / 块设备 / PCI / USB 信息 |
| `free -h` / `vmstat` | 内存使用 / 内存统计 |
| `top` / `htop` | 进程与资源占用（后者更美观、可交互） |
| `df -h` / `du -h` | 磁盘空间 / 目录大小 |
| `ip address` | 网络接口与 IP 地址 |
| `netstat -i` / `ifstat` / `iftop` | 网络流量（静态 / 连续 / 交互式） |
| `exit` | 退出登录 |
