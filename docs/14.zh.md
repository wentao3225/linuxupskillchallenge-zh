# 第 14 天 - 权限归谁？

* 教学视频：[Lesson video](https://youtu.be/mBcExazxLU8)（英文）
* 补充视频：[Permissions](https://www.youtube.com/live/2lYo_FJxQR8?t=6290s)（英文）

## 引言

Linux 系统上的文件总是带有与之关联的“权限”——控制谁能访问，以及能进行哪种访问。你其实已经以各种方式撞上过它了——举个例子，昨天你用“普通”用户登录时，既不能直接往 _/var/www_ 里上传文件，也不能在 _/_ 下创建新文件夹。

Linux 的权限系统相当简单，但确实有一些古怪而微妙的地方，所以今天只是对一些基本概念的入门介绍。

这一次，你*真的*需要把“资源”小节里的材料好好过一遍！

## 今日任务

* 把一个文件的属主改为 root（根用户）
* 修改文件权限

## 属主

先来看“属主”（ownership）。所有文件都同时标记着拥有它的用户名和用户组名，所以如果我们输入 `ls -l`，会看到这样的文件列表：

	-rw------- 	1 steve  staff  	4478979  6 Feb  2011 private.txt
	-rw-rw-r-- 	1 steve  staff  	4478979  6 Feb  2011 press.txt
	-rwxr-xr-x 	1 steve  staff  	4478979  6 Feb  2011 upload.bin

那么这些文件由用户“steve”和用户组“staff”拥有。任何不是“steve”、也不属于“staff”组的人都被视为“其他人”。其他人可能仍然有处理这些文件的权限，但他们并不拥有这些文件。

想修改文件的属主，用 `chown` 工具。下面这条命令会把 _file_ 的用户属主改成新用户：

`sudo chown user file`

也可以同时修改用户和用户组：

`sudo chown user:group file`

如果只需要修改组属主，可以改用 `chgrp` 命令：

`sudo chgrp group file`

上一课你已经创建了几个新用户，现在切换登录，在他们的家目录里创建一些测试文件，再用 `ls -l` 看看它们是如何显示的。

## 权限（符号表示法）

看目录列表行开头的 `-rw-r--r--`（暂时忽略第一个“-”），把它看成潜在的三组“rwx”：分别是授予文件属主“用户”的权限、“用户组”的权限，以及“其他人”的权限——我们喜欢称之为 [UGO](https://acronym24.com/ugo-meaning-in-linux/)。

对于上面那份示例列表：

* _private.txt_ —— steve 有 `rw`（即读和写）权限，但“staff”组和“其他人”连一点权限都没有
* _press.txt_ —— steve 同样能读写这个文件，“staff”组的任何成员也能；而*任何人*，也就是“其他人”，都可以读它
* _upload.bin_ —— steve 有 `rwx`，可以读、写、执行——也就是运行这个程序——但用户组和其他人只能读和执行

你可以用 `chmod` 工具修改任何文件的权限。用 `vim` 在家目录里创建一个简单的文本文件（比如 _tuesday.txt_），然后输入 `cat tuesday.txt` 或 `less tuesday.txt`，确认你能查看它的内容。

现在用 `ls -ltr tuesday.txt` 看看它的权限：

	-rw-rw-r-- 1 ubuntu ubuntu   12 Nov 19 14:48 tuesday.txt

可以看到，文件的用户属主和用户组都是“ubuntu”，只有他们能写入这个文件——其他任何用户都只能读。

## 修改权限

现在把用户和“ubuntu”用户组对自己文件的写权限去掉：

`chmod u-w tuesday.txt`

`chmod g-w tuesday.txt`

……再去掉“其他人”读这个文件的权限：

`chmod o-r tuesday.txt`

列一下目录确认结果：

	-r--r----- 1 ubuntu ubuntu   12 Nov 19 14:48 tuesday.txt

……再用 `nano` 或 `vim` 试着编辑它来确认。你会发现你似乎能编辑它——但保存不了任何改动。（在这种情况下，作为属主，你拥有“越过权限的权限”，所以可以用 `:w!` 强制写入。）当然，你也可以随时用下面这条命令轻松拿回写权限：

`chmod u+w tuesday.txt`

## 分享你的进度

## 本课命令速查（中文版新增）

| 命令 | 用途 |
| --- | --- |
| `ls -l` / `ls -ltr` | 查看属主与权限 / 按时间排序查看 |
| `sudo chown user file` | 修改文件的用户属主 |
| `sudo chown user:group file` | 同时修改用户属主和组属主 |
| `sudo chgrp group file` | 只修改组属主 |
| `chmod u-w` / `chmod g-w` / `chmod o-r` | 去掉用户 / 用户组 / 其他人的对应权限 |
| `chmod u+w` | 把写权限加回来 |
| `cat` / `less` | 查看文件内容 |
