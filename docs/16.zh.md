# 第 16 天 - 归档与压缩

## 引言

作为系统管理员，你需要能娴熟自如地处理文件的压缩“归档”（archive）。尤其是你的两项核心职责——安装新软件和管理备份——经常都要用到它。

在其他操作系统上，WinZip 这类应用（更早则是 `pkzip`）长期以来被用来把一组文件和文件夹收进一个压缩文件——扩展名为 `.zip`。

不过，归档和压缩实际上是两个不同的过程，只是经常搭配使用。归档把多个文件合并进一个“箱子”，同时保留它们的结构和属性，但并不改变数据总量；压缩则使用精巧的算法对数据高效编码，靠缩小这个文件来节省存储空间。

## 压缩文件

压缩的目标是减小文件体积。文件越小，占用的带宽越少，在网络上的传输也越快。不同的工具用不同的算法来真正把数据缩小。

可以用 GZip 这样压缩一个文件：

`gzip my-big-file`

……这会创建 `my-big-file.gz`，但会替换掉原文件。想保留未压缩的原件，试试：

`gzip -vk my-big-file`

这里 `-v` 让命令“话多”一点（verbose），`-k` 则保留原文件。

到了要解压的时候，用 `-d` 开关，像这样：

`gzip -d my-big-file.gz`

常用工具：

* [gzip](https://www.gnu.org/software/gzip/manual/gzip.html)：非常常见，速度快。
* [bzip2](https://man.archlinux.org/man/bzip2.1.en)：较慢，但通常压得更小。
* [xz](https://man.archlinux.org/man/xz.1.en)：目前 Linux 上最省空间的工具。

文本不管用哪个工具通常都能压缩得很好。JPEG/MP4 文件可能缩小不了多少——但这些格式本身已经做过一定压缩了。

## 创建归档

比如说，你可以这样给 _/etc/init.d_ 文件夹里现有的文件做一个“快照”：

`tar -cvf myinits.tar /etc/init.d/`

这会在你当前目录下创建 _myinits.tar_。

**注意 1：** `-f` 开关的含义是*“输出应写到紧随其后的那个文件名里”*——所以开关的顺序在这里很重要。**非常重要**：`tar` 会把 `-f` 之后的任何内容都当作要创建的归档名。因此，创建归档时应始终把 `-f` 放在最后一个。

**注意 2：** `-v` 开关（verbose）是为了给点反馈——按传统，很多工具只要不出错就一声不吭。

（“tar” 这名字很神秘？——它原本是 “tape archive”（磁带归档）的缩写。）

然后可以用 GnuZip 压缩这个文件：

`gzip myinits.tar`

……这会创建 `myinits.tar.gz`。像这样的压缩 tar 归档被称为 “tarball”。你有时也会见到 _.tgz_ 扩展名的 tarball——在 Linux 命令行上，这对系统没有任何意义，纯粹是方便人眼辨认。

实际操作中，可以用 `-z` 开关把两步合成一步，像这样：

`tar -cvzf myinits.tgz /etc/init.d/`

这里 `-c` 表示我们在创建归档；`-v` 让命令“话多”一点；`-z` 压缩结果；`-f` 指定输出文件。

## 解开归档

要“炸开”一个归档、取回你的文件，用 `-x`（extract）标志：

`tar -xvf archive.tar.gz`

**安全第一：** 解压之前，最好先用 `-t`（list）标志预览内容：

`tar -tf archive.tar.gz`

这样你就能对解压后的文件结构心里有数。如果列表里显示的许多文件没有共同前缀（比如 folder/file 这种形式），那你碰到的就是一颗 _tarbomb_（tar 炸弹）。不，不是[这一个](https://xkcd.com/1168/)。解压这种包可能把文件直接泼进你的当前目录，还可能覆盖已有的文件。

可以用 `-C` 标志把文件解到指定的目标目录，保持整洁：

`tar -xvf archive.tar.gz -C target_dir/`

## 扩展

你可能注意到，有些教程写的是 `tar cvf` 而不是带开关字符的 `tar -cvf`——你知道为什么吗？[提示](https://unix.stackexchange.com/questions/28403/tar-cvf-or-tar-cvf)：这与古老的 “tape archive” 风格和现代兼容性有关。

关于**压缩级别**的一点说明——大多数工具允许你用数字刻度（1–9）调节速度与体积之间的平衡：

* 级别 1：快，但压缩率低。
* 级别 6：默认设置；速度与体积的折中。
* 级别 9：压缩率最高（文件最小），但耗时最长。

不过，创建 tarball 时调用压缩工具，`tar` 只会用默认的级别 6。

## 本课命令速查（中文版新增）

| 命令 | 用途 |
| --- | --- |
| `gzip my-big-file` | 压缩文件（会替换原文件） |
| `gzip -vk my-big-file` | 压缩并保留原文件，显示过程 |
| `gzip -d my-big-file.gz` | 解压 |
| `tar -cvf myinits.tar /etc/init.d/` | 创建归档（`-f` 必须放在最后） |
| `gzip myinits.tar` | 把归档压成 tarball |
| `tar -cvzf myinits.tgz /etc/init.d/` | 一步完成“归档 + gzip 压缩” |
| `tar -tf archive.tar.gz` | 解压前预览归档内容（防 tarbomb） |
| `tar -xvf archive.tar.gz` | 解开归档 |
| `tar -xvf archive.tar.gz -C target_dir/` | 解压到指定目录 |
