# 第 8 天 - 大名鼎鼎的 “grep” 与其他文本工具

* 教学视频：[Lesson video](https://youtu.be/kG5JGJN5iTc)（英文）
* 补充视频：[Text Processing and other useful command line tools](https://www.youtube.com/live/WtcX60n-ui0?t=2517s)（英文）

## 引言

你的服务器现在正运行着两个服务：你用来登录的 *sshd*（Secure Shell Daemon）服务，以及 Apache2 web 服务器。当你和其他人访问服务器时，这两个服务都会不断生成日志——它们都是文本文件，我们可以用一些简单的工具来分析。

纯文本文件是“Unix 之道”的关键一环，围绕它有许许多多的小“工具”，让你能轻松地编辑、排序、搜索以及以其他方式处理文本。今天我们就用 `grep`、`cat`、`more`、`less`、`cut`、`awk` 和 `tail` 来切分摆弄你的日志。

`grep` 命令之所以出名，一是因为它极其强大又顺手，二是因为它那“极客味”十足的名字正是 Unix/Linux 命名传统的典型代表。

## 今日任务

* 用 `cat` 把文件的完整内容倾倒出来，像这样：`cat /var/log/apache2/access.log`
* 用 `less` 打开同一个文件，像这样：`less /var/log/apache2/access.log`——用方向键上下翻动，然后按 “q” 退出。
* 依然用 `less` 查看文件，但练习自信地在文件中移动：*gg*、*GG* 和 */*、*n* 与 *N*（分别用于跳到文件开头、跳到文件末尾、搜索某样东西，以及跳到下一个“命中处”或回到上一个）
* 用 `less` 查看 `/var/log/auth.log`，了解最近的登录和 `sudo` 使用情况
* 用 `tail /var/log/apache2/access.log` 只看文件的末尾几行（没错，还有一个 `head` 命令！）
* 用 `tail -f /var/log/apache2/access.log` 实时跟踪日志（同时在浏览器里访问你服务器的网页）
* 你可以用 `|`（管道）符号，把一条命令的输出“接”为另一条命令的输入
* 于是，先用 `cat` 倒出文件，再把输出通过管道交给带搜索词的 `grep`——像这样：`cat /var/log/auth.log  | grep "authenticating"`
* 还可以简化成：`grep "authenticating" /var/log/auth.log`
* 管道能让你层层缩小搜索范围，比如 `grep "authenticating" /var/log/auth.log | grep "root"`
* 用 `cut` 命令配合 “-d”（分隔符）和 “-f”（字段）参数，挑出每行里最有意思的部分——例如：`grep "authenticating" /var/log/auth.log| grep "root"| cut -f 10- -d" "`（从第 10 个字段取到末尾，字段之间的分隔符是空格 “ ”）。想从日志数据里提取有用信息时，这一招非常好用。
* 用 `-v` 选项反向选择，找出用其他用户登录的尝试：`grep "authenticating" /var/log/auth.log| grep -v "root"| cut -f 10- -d" "`

任何命令的输出都可以用 “>” 运算符“重定向”到文件。`ls -ltr > listing.txt` 这条命令不会把目录内容列到屏幕上，而是写进文件 “listing.txt”（文件不存在就创建，已存在就覆盖其内容）。

## 找不到 /var/log/auth.log？

如果你没找到 `/var/log/auth.log` 这个文件，你用的多半是最小化版本的 Ubuntu（可能是你自己的本地虚拟机，也可能是某家 VPS（虚拟专用服务器）提供的镜像）。这种最小化镜像嘛……确实“最小”。它只有 systemd journal 可用，默认并不带旧的 syslog 系统。

不过别担心！执行 `sudo apt install rsyslog` 装回 rsyslog，文件就会被创建出来。开始学这一课之前，先给它几分钟时间写入内容。

它可能还缺了课程里会用到的其他一些程序，不过你随时可以把它们装上。

## 扩展

* 试试能否把对 `auth.log` 的筛选再推进一步，只留下 IP 地址，然后把结果通过管道交给 `sort`，再交给 `uniq`，得到一份替你“审计”过服务器安全的 IP 地址清单。
* 研究一下 `awk` 和 `sed` 命令。当你发现用 `grep` 和 `cut` 想不明白该怎么完成某件事时，可能就该请出这两位了。搜索 “linux sed tricks” 或 “awk one liners”，能找到大量示例。
* 给自己定个目标：`awk` 和 `sed` 各至少学会一个简单实用的小技巧

## 本课命令速查（中文版新增）

| 命令 | 用途 |
| --- | --- |
| `cat 文件` | 输出文件完整内容 |
| `less 文件` | 分页查看：`gg` / `GG` 跳到开头 / 结尾，`/` 搜索，`n` / `N` 跳下一个 / 上一个命中，`q` 退出 |
| `tail 文件` | 查看文件末尾几行 |
| `tail -f 文件` | 实时跟踪日志 |
| `head 文件` | 查看文件开头几行 |
| `grep "词" 文件` | 按关键词过滤行 |
| `grep -v "词"` | 反向过滤，排除匹配行 |
| `cut -f 10- -d" "` | 按分隔符截取第 10 个字段及之后的内容 |
| `sort` / `uniq` | 排序 / 去重（接在管道后统计来源 IP 很好用） |
| `awk` / `sed` | 更强的文本处理工具（见“扩展”一节） |
| `命令 > 文件`（如 `ls -ltr > listing.txt`） | 把输出重定向到文件（覆盖写入） |
| `sudo apt install rsyslog` | 装回 rsyslog，恢复 `/var/log/auth.log` |
