# 第 19 天 - inode、符号链接与其他捷径

## 引言

今天的话题带你“掀开机盖”，看一看文件在技术上是如何存储的。

Linux 支持多种不同的“文件系统”（filesystem）——虽然在服务器上你打交道的通常只有 _ext3_ 或 _ext4_，或许还有 _btrfs_——但今天我们要说的并不是其中任何一种，而是凌驾于它们之上的一层：Linux 虚拟文件系统（VFS）。

VFS 是 Linux 的关键组成部分，对它和它周边的几个概念有个概览，会让你管理系统时更有底气。

## 今日任务

* 创建一个硬链接（hard link）
* 创建一个软链接（symlink）
* 创建别名（alias）

## 再往下一层

在文件名和磁盘上文件的实际数据之间，Linux 还有额外的一层——这就是 _inode_。它有一个数值，最方便用两种方式查看：

`ls` 命令的 `-i` 开关：

     ls -li /etc/hosts
     35356766 -rw------- 1 root root 260 Nov 25 04:59 /etc/hosts

`stat` 命令：

     stat /etc/hosts
       File: `/etc/hosts'
       Size: 260        	Blocks: 8          IO Block: 4096   regular file
     Device: 2ch/44d	Inode: 35356766    Links: 1
     Access: (0600/-rw-------)  Uid: (	0/	root)   Gid: (	0/	root)
     Access: 2012-11-28 13:09:10.000000000 +0400
     Modify: 2012-11-25 04:59:55.000000000 +0400
     Change: 2012-11-25 04:59:55.000000000 +0400

每个文件名都“指向”一个 inode，而 inode 再指向磁盘上的实际数据。这意味着几个文件名可以指向同一个 inode——因此内容也就完全一样。这其实是一种标准技术，叫“硬链接”（hard link）。另一个值得注意的要点是：当我们查看文件名的权限、属主和日期时，这些属性实际保存在 inode 层面，_而不是_文件名上。多数时候这种区别只是理论性的，但它可能非常重要。

## 两种链接 { #two-sorts-of-links }

跟着下面的步骤，把硬链接和软链接练熟：

先用这条命令回到你的主目录：

`cd`

然后用 `ln`（“link”）命令创建一个“硬链接”，像这样：

`ln /etc/passwd link1`

再创建一个“符号链接”（symbolic link，简称“symlink”，即软链接），像这样：

`ln -s /etc/passwd link2`

现在用 `ls -li` 查看这两个新文件，再用 `less` 或 `cat` 看看它们的内容。

注意，符号链接自身的权限通常显示为完全放开——但真正起作用的，是它所指向文件的权限。

硬链接和符号链接在 Linux 里都很常用，而符号链接尤其普遍——比如：

`ls -ltr /etc/rc2.d/*`

这个目录存放着你的机器切换到“运行级别 2”（runlevel 2，即正常运行状态）时要启动的全部脚本——但你会看到，其中大部分其实是指向 _/etc/init.d_ 里真正脚本的符号链接。

> **译注**：在现代 systemd 系统上，这些目录只是向后兼容的历史遗留，真正的开机启动由 systemd 的 unit 与 target 接管；这里用它练软链接没问题，但别把它当成现在的启动机制。

也很常见的做法是弄出类似这样一组文件：

     prog
     prog-v3
     prog-v4

其中程序 “prog” 本身是个符号链接——最初指向 v3，现在指向 v4（需要时也可以再指回去）。

读一读下面给出的资源，并在你的服务器上动手测试，以加深理解。特别要观察：符号链接与硬链接、普通文件相比，权限和文件大小分别是怎么表现的。

## 两者的区别

硬链接：

* 只能链接到文件，不能链接到目录
* 无法引用另一块磁盘/卷上的文件
* 即使原文件被移动，链接仍然引用它
* 链接引用的是 inode，也就是磁盘上的物理位置

符号链接（软链接）：

* 可以链接到目录
* 可以引用另一块硬盘/卷上的文件或文件夹
* 原文件被删除后，链接依然存在
* 原文件一旦被移动，链接就不再指向它
* 链接引用的是抽象的文件名/目录名，_而不是_物理位置
* 它们有自己的 inode

## 本课命令速查（中文版新增）

| 命令 | 用途 |
| --- | --- |
| `ls -li /etc/hosts` | 用 `-i` 查看文件的 inode 号 |
| `stat /etc/hosts` | 查看 inode、权限、属主、时间戳等元数据 |
| `ln /etc/passwd link1` | 创建硬链接（与原文件共用同一个 inode） |
| `ln -s /etc/passwd link2` | 创建符号链接（软链接，有自己的 inode） |
| `ls -li link1 link2` | 对比两种链接的 inode、权限与大小差异 |
| `ls -ltr /etc/rc2.d/*` | 查看运行级别目录里的符号链接（SysV 历史兼容层） |
| `alias` / `unalias 别名` | 查看 / 删除 shell 别名（对应今日任务的“创建别名”） |
