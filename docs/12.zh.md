## 引言

你已经拥有自己的联网服务器一段时间了，也见识了怎么在上面创建和编辑小文件，还搭好了一个 web 服务器，编辑过简单的网页。

今天我们来看怎么在你的其他设备和这台服务器之间传输文件，比如：

* 把服务器上的一些文件复制一份到你的本地电脑上
* 把一些文本传到服务器上，放到你的网页里
* 为你的网页上传一些照片和 logo

## 今日任务

* 上传一个文件到服务器
* 从服务器下载一个文件
* 同步一份备份

## 协议

Linux 服务器共享文件的方式五花八门，包括：

* SMB：微软的文件共享协议，适合 Windows 机器组成的局域网
* AFP：苹果的文件共享协议，适合苹果机器组成的局域网
* WebDAV：基于 web（http）协议的共享
* FTP：传统的互联网共享协议
* scp：简单的文件复制
* rsync：快速、非常高效的文件复制
* SFTP：通过 SSH 协议进行文件访问和复制（尽管名字像，SFTP 协议在技术层面与传统 FTP 完全无关）

这些协议各有各的用武之地，但就“在你的本地电脑和服务器之间来回拷文件”这件事而言，SFTP 有几个关键优势：

* 服务器端无需任何额外配置
* 安全性一流
* 可以浏览整个目录结构
* 可以创建和删除文件夹

只要你能从家里、公司或网吧通过 _ssh_ 成功登录，那么在同样的地方你也能用 SFTP——因为两者底层走的是同一个协议。

相比之下，让服务器支持其他任何一种协议都要额外下功夫。不仅如此，多开一种协议就多一分“攻击面”（attack surface）——总有几率你某个配置没弄对，给攻击者留了门。公司里严格的防火墙策略也很容易干扰甚至直接封掉这些协议。最后，老式 FTP 如今仍很常见，但它把登录凭据“明文”发送出去——你的室友、咖啡馆邻座或雇主都可能通过网络“抓包”把它们截走。对你的“课堂”服务器来说这不是大事——但如果你远程管理的是生产服务器，这种风险就不可接受了。

## SFTP 客户端软件

使用 SFTP 需要客户端软件。macOS 和 Linux 系统都自带命令行客户端（不出意外就叫 _sftp_）。如果你用的是 Linux 桌面版，文件管理器里还内置了图形客户端，可以轻松通过 SFTP 连接远程服务器。（以 Nautilus 文件管理器为例，按 `ctrl + L` 呼出“位置栏”，输入 _sftp://username@myserver-address_ 即可。）

Windows 和 macOS 虽然没有内置图形客户端，但第三方选择很多，免费和收费的都有。如果你还没装过这类客户端，可以从下面挑一个：

* WinSCP 或 FileZilla——Windows 用户
* CyberDuck 或 FileZilla——macOS 用户

下载地址见文末“资源”一节。

这些客户端的配置和使用都很直观。唯一可能让你犯迷糊的是：它们一般支持一大堆协议（比如 scp 和 FTP），而我们并不打算用那些。填写连接信息时，SERVER 填服务器的 IP 地址，PORT 填 22，PROTOCOL 选 SFTP 或 SSH。

## 操作步骤

* 配置你选定的 SFTP 客户端，用你的用户名登录服务器
* 从服务器复制一些文件到本地电脑（试试“home”目录里的文件，以及 `/var/log` 里的）
* 在服务器上你的“home”目录下建一个 “`images`” 文件夹，再从本地电脑上传几张图片进去
* 一路向上走到根目录，你会看到 `/etc`、`/bin` 等文件夹。试着在这里也建一个 “`images`” 文件夹——这应该会失败：你是以普通用户身份登录的，没有权限新建文件或文件夹。而在你自己的“home”目录里，你当然拥有完整的权限。

文件上传之后，你可以通过 _ssh_ 登录，再用 `sudo` 给自己足够的权限来挪动文件。

## 本课命令速查（中文版新增）

| 命令/工具 | 用途 |
| --- | --- |
| `sftp` | 命令行 SFTP 客户端（macOS / Linux 自带） |
