# 第 4 天 - 安装软件、探索文件结构

* 教学视频：[Lesson video](https://youtu.be/d8JzxgGNAx4)（英文）
* 补充视频：[APT](https://www.youtube.com/live/mI0nfnkr0J0?t=12205s)（英文）

## 引言

作为系统管理员，按需安装新软件是你的关键任务之一。你还需要非常熟悉 Linux 系统中标准目录的布局。

今天的课程会同时在这两个方面给你练习机会。

## 今日任务

* 从在线软件仓库安装一个新应用
* 熟悉一部分标准目录
* 看看若干配置文件的格式和内容

如果你用过智能手机上的“应用商店”或“应用市场”，那你立刻就能理解从标准软件仓库安装 Linux 软件的常规流程。只要知道软件包（=应用）的名字或描述，我们就可以搜索：

     apt search "midnight commander"

这会列出一批匹配的“软件包”，然后用 `apt install` 命令安装即可。比如在 Ubuntu 上安装 `mc`（Midnight Commander）：

     sudo apt install mc

（除非你已经以 `root` 用户登录，否则安装命令前面都要加上 `sudo`——因为普通用户无权安装可能影响整台服务器的软件）

现在 `mc` 已经装好，输入 `mc` 再按 *Enter* 就能启动它。

这不算“经典”的 Unix 应用，但只要熬过那股复古劲，你会发现导航相当容易。去找找这些目录：

`/root`
`/home`
`/sbin`
`/etc`
`/var/log`

……然后借助下方“资源”小节里的链接，开始理解这些目录各自的用途。你也可以输入 `man hier`，阅读关于这套层级结构的官方手册。

大多数关键配置文件都保存在 `/etc` 及其子目录之下。这些文件和 `/var/log` 下的日志几乎无一例外都是简单的文本文件。接下来几天你会和它们打很多交道——但现在先用 F3 看看里面的内容即可。

值得一看的有趣文件有：`/etc/passwd`、`/etc/ssh/sshd_config` 和 `/var/log/auth.log`

再按一次 F3 退出文件浏览。

按 F10 可以退出 `mc`，不过你可能得用鼠标去选它。

（在 Apple Mac 的终端里，你可能需要用 ESC+3 来代替 F3，用 ESC+0 代替 F10）

现在用 `apt search` 再搜索、安装几个软件包：试试搜索 “hangman”。你大概会发现一个老式的文字版就藏在名为 `bsdgames` 的软件包里。装上它，玩上几局吧……

## 扩展

* 用 `mc` 打开 `/etc/apt/sources.list.d/ubuntu.sources` 看看——软件仓库的实际位置就在这里指定。这些位置往往是“镜像”站点，比 Ubuntu 的主服务器离你的服务器更近。
* 想了解更多细节，请读 [Repositories - CommandLine](https://ubuntu.com/server/docs/how-to/software/package-management/)。

## 本课命令速查（中文版新增）

| 命令 | 用途 |
| --- | --- |
| `apt search "<关键词>"` | 在软件仓库中按名称/描述搜索软件包 |
| `apt install <包名>` | 安装软件包（普通用户需加 `sudo`） |
| `mc` | 启动 Midnight Commander 文件管理器（F3 查看文件、F10 退出） |
| `man hier` | 查看文件系统目录层级的官方说明 |
