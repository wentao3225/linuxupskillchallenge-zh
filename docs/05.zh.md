## 引言

今天的课程用一个漂亮的压轴收尾——一口气快速过一遍五个不同的主题。今天不求精通——接下来的课程里，你会有大把机会反复练习它们！

别被这些命令看似简单的外表骗了——它们个个深藏不露，很多系统管理员每天都会用到其中的好几条。

## 今日任务

* 练习 Tab 补全（tab completion）
* 在命令历史中搜索
* 用 `more` 和 `less` 阅读点文件
* 修改 / 定制你的提示符

可以借助“资源”小节里的链接完成这些任务：

* 熟悉用 `more` 和 `less` 查看文件，包括在 `less` 里跳到文件的顶部或底部，以及搜索指定的文字

* 试试“Tab 补全”是怎么工作的——这是个能帮你把命令敲对的好用功能。它既能补全命令本身，也能补全文件名参数：输入 `les` 再按 “Tab”，会补全成命令 `less`；输入 `less /etc/serv` 再按 “Tab”，则会补全成 `less /etc/services`。试着输入 `less /etc/s` 然后按 “Tab”，再按一次，看看这个功能是如何处理歧义的。

* 到现在你已经敲了不少命令，试试按“上方向键”往回翻。你会发现不但能看到最近的命令——连上次登录时敲过的命令也都在。再来试试 `history` 命令——它会把缓存下来的整段命令历史列出来——常有 100 条以上。拿它能玩出不少聪明的花样。最简单的一招是重复执行某条命令——挑一行（比如第 20 行），输入 `!20` 再按 “Enter”，这条命令就被重新执行了。等你以后要输入又长又复杂的命令时，这会 *非常* 好用。你也可以按 `Ctrl + r`，然后开始输入你要找的那条命令的任意片段，提示符上就会出现历史命令的自动补全。继续输入，候选会越来越精确。此时既可以按回车直接执行，也可以先用方向键或其他移动键编辑一下再执行。反复按 `Ctrl + r`，还能看到你用过的同一条命令配上不同选项的其他实例。

* 到家目录里找找“隐藏”文件。Linux 的约定很简单：凡是以 “.” 字符开头的文件都是隐藏的。输入 `cd` 回到你的“家目录”，然后 `ls -l` 看看那里有哪些文件。再输入 `ls -la` 或 `ls -ltra`（“a” 代表 “all”）来显示全部文件——包括以点开头的那些。“点文件”（dotfile）最常见的用途，就是把个人设置保存在家目录里。所以，用你刚学会的 `less` 技能去看看 `.bashrc`、`.bash_history` 等文件的内容吧。

* 最后，用 `nano` 编辑器在家目录里创建一个文件，写下这五天课程学下来的一点心得总结。

## 扩展

目前我们用的终端 shell 是 `bash`（许多发行版的标配），但它并不是唯一的选择。如果想试试 [zsh](https://www.geeksforgeeks.org/how-to-install-z-shellzsh-on-linux/)、[fish](https://fishshell.com/) 或 [oh-my-zsh](https://ohmyz.sh/)，你会发现它们之间存在一些差异，而功能通常是最主要的区别。动手试试，四处逛逛。

之后还可以更进一步：用一个**终端复用器**（terminal multiplexer）在同一个终端窗口里同时开好几个 shell 会话。可以试试 [screen](https://linuxize.com/post/how-to-use-linux-screen/)——它稍简单一些，但一开始可能显得过于简陋——或者功能繁多、色彩丰富的 [tmux](https://github.com/tmux/tmux/wiki)。网上关于“如何定制你的 tmux”的资料铺天盖地，玩得开心。

## 本课命令速查（中文版新增）

| 命令 | 用途 |
| --- | --- |
| `Tab` | 补全命令名 / 文件名参数 |
| 上方向键 | 翻看历史命令（含上次登录会话） |
| `history` | 列出整段缓存命令历史 |
| `!20` | 重复执行第 20 条历史命令 |
| `Ctrl + r` | 按片段反向搜索历史命令 |
| `ls -l` / `ls -la` / `ls -ltra` | 列出文件 / 连隐藏文件一起列出 |
| `more` / `less` | 分页查看文件内容 |
| `cd` | 回到家目录 |
| `nano` | 创建并编辑文件 |
