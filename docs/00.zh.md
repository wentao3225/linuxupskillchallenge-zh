## 前提要求

首先，你需要一台服务器。没有一台属于自己的服务器，你学不会管理远程 Linux 服务器——所以今天我们就去弄一台。

借助 Linux 和虚拟化的魔力，如今几乎一瞬间就能弄好一台连上互联网的小型服务器——而且价格非常低。严格来说，你要做的是创建并租用一台 VPS（虚拟专用服务器）。在某个数据中心里，一台运行 Linux 的物理服务器会借助 KVM（基于内核的虚拟机，Kernel-based Virtual Machine）特性被切分成十几台甚至更多的虚拟机——这个特性自 2007 年初起就是 Linux 的一部分——而你只是租用其中一小部分硬件算力来运行自己的小服务器。

> **译注**：云厂商价格与免费额度变动频繁，以官方页面为准。

总而言之，**你将在某处的物理计算机里创建一台虚拟机（VM）**。这个“某处”[最理想是放在云厂商的数据中心里](how-this-works.md#do-i-really-need-a-cloud-based-server)，但你也完全可以使用自己的个人电脑或其他现成硬件，只要它有网络连接，能够：

* 进行软件更新和安装
* 通过 SSH 远程访问

无论你的虚拟机跑在哪里，本课程涉及的大多数命令都完全一样。

除了托管服务商，我们还要选择在服务器上安装哪种“口味”的 Linux。如果你是 Linux 新手，琳琅满目的“发行版”可能让人眼花缭乱——不过 Ubuntu Server 最新的 LTS（长期支持版）是个流行的选择，[本课程用的就是它](how-this-works.md#why-ubuntu-can-i-use-another-distro)。

## 可是……你们有免费的服务器给我用吗？

我们刚在 [Killercoda](https://killercoda.com/linux-upskill-challenge) 上线了一个**基础测试场景**，你可以按原样跑完所有课程（第 12 天除外）。各课的独立场景仍在开发中，但现在你就已经有一台基本就绪的 Ubuntu 服务器了，免去搭建虚拟机、折腾 SSH 密钥的麻烦。

[SadServers](https://sadservers.com) 也有一个[测试版场景](https://sadservers.com/scenario/luc)，提供一台空白的 Debian 11 服务器，但有一些限制。如果你对 Linux 已有几分熟悉，宁愿做场景练习也不想自己搭服务器，SadServers 是练习排障技能的好地方。

## 那么，该怎么选？

**[本地服务器或本地虚拟机](00-Local-Server.md)：** 如果完全不想跟云厂商打交道，这是个合理的选择。WSL 让许多人第一次接触 Linux 就轻松上手，VirtualBox 则是久经考验的虚拟化软件。不管怎么说，这都是进入 Linux 世界的元老级路子。*至少不会有人劝你去装双系统。*

**[上云（选用 DigitalOcean、Linode、Vultr 这类厂商）](00-VPS-small.md)：** 比大厂更轻量、也没那么多繁文缛节，你对服务器有相当大的掌控权，服务器该如何表现，也要由你做更多决定。这是许多学完 Linux Upskill Challenge 的人的首选。

**[上云（选用 AWS、Azure、Google Cloud 这类厂商）](00-VPS-big.md)：** 看看这些大厂对你来说是否划算，学生尤其值得一看。教育优惠包和期限最长的免费额度都在这一类里。“云上恐怖故事”大多也发生在这里。不过，大家往往忘了告诉你，究竟是哪些产品和配置炸穿了他们的账单——*剧透一下：绝不会只是一台最小配置的服务器*。

> **译注**：云厂商价格与免费额度变动频繁，以官方页面为准。

把选项都看一遍，挑最适合自己的。抽点时间看看那个[补充视频](https://youtube.com/live/_-6UYOjRIVQ)，它能解答你的大部分疑问。
