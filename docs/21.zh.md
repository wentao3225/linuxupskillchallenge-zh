# 第 21 天 - 下一步？

* 教学视频：[Lesson video](https://youtu.be/MW9q6NWNDyM)（英文）

这是什么情况——这门课不是只有 20 天吗？

没错，但希望你能继续学下去，所以这里给出几个可以考虑的方向。

## 继续玩你的服务器

课程用的那台服务器你已经很熟悉了，继续拿它练手吧。也许卸掉 Apache2，装上竞品 NGINX？或者持续统计 ssh“攻击者”的动向？都可以。免费的 AWS 能用一年，每月 5 美元的服务器，你也总能给自己找到一个说得过去的理由。

## 加几个你会用到的服务

现在你应该有能力照着教程，安装并运行自己的 Minecraft、Wordpress、WireGuard VPN 或 Mediawiki 实例了。过程中难免遇到些问题——那都是宝贵的经验！

可以看看 [Server World](https://www.server-world.info/en/note?os=Ubuntu_22.04&p=httpd&f=1)，找找灵感。

## 延伸学习

别再刷 Gnome、KDE 或 i3 的文章了——去看看“*20 Linux commands every sysadmin should know*”这类文章吧。动手试试这些命令，深挖它们的选项。就像学外语要背单词，这些“词”你得先认识，才谈得上使用！

如果还没逛过 [Linux Journey](https://linuxjourney.com/)，不妨去看看——尤其当你对 Linux 还很陌生、想见识一种不同的学习路径时。[Linux 101 Hacks](https://linux.101hacks.com/toc/) 也是个好资源。

到 [SadServers.com](https://sadservers.com/) 做些挑战题，练一练你学到的东西。那里收集了一系列场景，你要在其中对一台 Linux 服务器完成操作、修复问题，甚至“黑”进去。不用拿自己的服务器冒险就能锻炼排障技能，非常划算。

想让命令行速度突飞猛进，试试 [Command Line Challenge](https://cmdchallenge.com/)、[practicelinux.com](https://www.practicelinux.com/home)、[learnshell.org](https://www.learnshell.org/) 和 [commandlinefu.com](https://www.commandlinefu.com/commands/browse)。

如果你的进阶目标是转入 DevOps，可以看看 [DevOps Roadmap](https://roadmap.sh/devops)。

## 认证

如果你想以 Linux 为职业，而手上还没有一份亮眼的简历，那就该把拿到一张 Linux 认证作为目标。真正算数的证书/路线其实只有三条：

* [CompTIA Linux+](https://www.comptia.org/certifications/linux) —— 一次考试搞定，不绑定发行版，但市场上含金量不算高。如果你不想深入 Linux，或者你本来就在修其他 CompTIA 路线、而且雇主愿意报销，那就选它。
* [LPI LPIC-1: Linux Administrator](https://wiki.lpi.org/wiki/Main_Page) —— 对其各类认证/课程的覆盖范围有非常详尽的说明。这些考试可以钻得很深，凡是纯 Linux 能想到的内容几乎都有覆盖。雇主认可度不算高，但知识本身绝对保值。
* [Red Hat](https://www.redhat.com/en/services/all-certifications-exams) —— 你可能在这里花掉大量时间和金钱，但很可能物有所值！它面向 RedHat Enterprise Linux 发行版及其独有之处，是实操考试（其他两家都是选择题），在企业圈里名声很响，简历上非常亮眼。

即便你不想要/不需要证书，这些参考资料里的大纲也能帮你在自学中找准该发力的方向。
