    第 7 天 - 服务器与其服务

    • 教学视频：Lesson video（英文）
    • 补充视频：Apache and System Services（英文）

    引言

    今天你将安装一个常见的服务器应用——Apache2 网页服务器，也叫 httpd——“Hyper Text Transport Protocol Daemon”（超文本传输协议守护进程）！

    如果你是网站行业的老手，做法也许会稍有不同，但我们这里的重点既不在 Apache 本身，也不在网站内容，而在于更好地理解：

    • 应用安装
    • 配置文件
    • 服务
    • 日志

    今日任务

    • 安装并运行 Apache，把你的服务器变成一台 网页服务器（web server）

    操作步骤

    • 用 sudo apt update 刷新可用软件包（应用）列表——这一步要花上一两分钟，但能确保你装到的是最新版本。
    • 用一条简单的 sudo apt install apache2，从软件仓库安装 Apache。
    • 用浏览器访问 http://[external IP of your server] 确认它已经在运行——你应该会看到一个确认页面。
    • Apache 是作为“服务”安装的——服务是一种随服务器启动而自动启动、无论有没有人登录都持续运行的程序。试试用 sudo systemctl stop apache2 停掉它——看看网页是不是挂了——再用 sudo systemctl start apache2 重新启动，并用 systemctl status apache2 查看它的状态。
    • 和绝大多数 Linux 软件一样，配置由 /etc 目录下的文件掌管——去看看 /etc/apache2 下的配置文件，尤其是 /etc/apache2/apache2.conf。想纯看看内容，用 less 就行；想看又想改，就用 vim 编辑器。
    • /etc/apache2/apache2.conf 里有一行写着：“IncludeOptional conf-enabled/*.conf”。它告诉 Apache：子目录 conf-enabled 下的那些 *.conf 文件，要在加载时与来自 /etc/apache2/apache2.conf 的内容合并。这种“一堆小而专的配置文件”的思路很常见。
    • 如果你本来就熟悉 Web 服务器配置，那就放开手脚：配几个虚拟主机（virtual host），或者加一些模块等等。
    • 默认网页放在哪里，由 /etc/apache2/sites-enabled/000-default.conf 文件中的 DocumentRoot 参数决定。
    • 用 less 或 vim 看看默认页面的代码——它通常在 /var/www/html/index.html。这份代码用了相当复杂的现代网页设计——所以在你的 ssh 会话里运行 sudo vim /var/www/html/index.html，先把现有内容删掉（用你昨天学到的 vim 技巧），再换成一段更简单的代码。直接放纯文本也能正常工作，显示简单文字并不需要加 HTML 标签。不过，你也可以先逛逛我们的示例服务器 http://142.93.60.184/，用我们的示例代码。然后在你的工作站浏览器里再次访问 http://[external IP of your server] 查看结果。
    • 和大多数 Linux 服务一样，Apache 把日志放在 /var/log 目录下——去看看 /var/log/apache2 里的日志。在 access.log 文件里，你应该能找到自己刚才浏览测试页的那次访问记录。注意，里面的细节多得吓人——这很典型，后面的课程里你会学到如何只筛出自己想要的内容。也留意一下 error.log——但愿它是空的！

    AWS/Azure/GCP/OCI 用户须知

    别忘了把 80 端口加进你实例的安全组（security group），放行到你服务器的入站流量。

    • AWS
    • Azure
    • GCP
    • Oracle Cloud Infrastructure

    分享你的进度

    练一练你的文本编辑技能：用 vim 编辑 /var/www/html/index.html，再把访问它的 URL 贴到论坛里，让“同学们”来评判你的进步。（不用做得多好看！）

    安全

    • 作为这台服务器的系统管理员，你要对它的安全负责，因此必须非常清楚：你已经增大了服务器的“攻击面”（attack surface）。除了 22 端口上的 ssh，你现在还把 apache2 暴露在了 80 端口上。假以时日，日志里会陆续出现来自各路搜索引擎和攻击者的访问记录——这完全正常。
    • 运行 sudo apt update，再运行 sudo apt upgrade 并接受建议的升级，你就能拿到全部最新安全更新，对测试环境来说足够安全——不过这套命令你应该定期重跑。

    本课命令速查（中文版新增）

    命令 用途
    sudo apt update 刷新可用软件包列表
    sudo apt install apache2 安装 Apache2
    sudo systemctl stop apache2 / sudo systemctl start apache2 停止 / 启动 Apache 服务
    systemctl status apache2 查看 Apache 服务状态
    less /etc/apache2/apache2.conf 查看 Apache 配置
    sudo vim /var/www/html/index.html 编辑默认网页
    less /var/log/apache2/access.log 查看访问日志（error.log 同理）
